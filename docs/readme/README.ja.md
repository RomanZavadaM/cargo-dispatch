## 製品について

**cargo-dispatch** は、小型トラック(車両総重量 7.5 t 以下)の車両群向けに市場から貨物を選び、途中の追加積載を含む運行を組み、配車担当者が車両の動きを管理できるようにします。開発言語:Rust。
