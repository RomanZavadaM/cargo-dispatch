## 产品简介

**cargo-dispatch** 为小型货车车队(总质量不超过 7.5 吨)从市场中挑选货源,编排包含途中追加装货的行程,并让调度员掌握车辆行驶情况。开发语言:Rust。

## 界面语言

当前 UI 原型已实现并验证 **乌克兰语、英语和德语**。其他 README 翻译属于文档语言或后续目标语言，并不表示程序界面目前已经支持这些语言。
