## 제품 소개

**cargo-dispatch**는 소형 트럭 차량군(총중량 7.5톤 이하)을 위해 시장의 화물을 선별하고, 경로상 추가 적재를 포함한 운행을 구성하며, 배차 담당자가 차량 이동을 관제하도록 합니다. 개발 언어: Rust.

## 인터페이스 언어

현재 UI 프로토타입에서 구현 및 검증된 언어는 **우크라이나어, 영어, 독일어**입니다. 그 밖의 README 번역은 문서용 또는 향후 목표 언어이며, 현재 프로그램 UI에서 지원된다는 뜻은 아닙니다.
