## Rust-бібліотеки

У routing-probe прямо використовуються:

- `serde 1.0.229` — MIT OR Apache-2.0 — серіалізація структур даних;
- `serde_json 1.0.154` — MIT OR Apache-2.0 — робота з JSON;
- `sha2 0.10.9` — MIT OR Apache-2.0 — SHA-256 для ідентифікаторів профілю, набору даних і кешу.

Повний набір прямих і транзитивних Rust-залежностей зафіксований у `Cargo.lock` і перевіряється автоматично за `deny.toml`.

## Routing probe та інструменти перевірки

- Valhalla 3.9.3 — MIT. У цій гілці використовується лише як зафіксований Docker-образ для технічної перевірки маршрутизації; у готовий продукт поки не входить.
- Osmium Tool — GPL-3.0. Використовується лише в GitHub Actions для перетворення синтетичного тестового OSM-файлу в PBF; у cargo-dispatch не вбудовується і з продуктом не розповсюджується.
- libxml2 / xmllint — MIT-style license. Використовується лише в GitHub Actions для перевірки синтетичного XML-файлу.

Якщо будь-який із цих інструментів пізніше стане частиною розповсюджуваного продукту, його спосіб постачання і ліцензійні обов'язки мають бути перевірені окремо до релізу.
