# Актуальний стан — cargo-dispatch

Оновлено: 2026-11-27, Europe/Kyiv.

Короткий публічний стан; деталі — приватно.

- Стабільна версія: **v0.3.0**.
- Інтегровано: Control і Planner (Windows, macOS, Linux), сторінка водія в браузері, застосунки Android та iPhone/iPad, Addressing Gateway, вісім мов інтерфейсу.
- Control лишається єдиним джерелом факту активного рейсу; Gateway не зберігає рейсів, документів, медіа чи позицій.
- У v0.2.0: паритет застосунків водія зі сторінкою водія, повідомлення про помилки вісьмома мовами, читабельні дані в картці рейсу.
- У v0.3.0: Planner від файла заявок через варіанти маршрутів до пакета рейсу, збереження введеного між запусками, відновлення Control після перезапуску.
- Вручну перевірено (на ранішій тестовій збірці): Control для Windows і сторінка водія на планшеті в локальній мережі. Пізніші зміни вікна Control, сторінки водія й застосунків перевірені лише автоматично та віртуально.
- Вікно Planner проходиться в браузері без вікна разом зі справжньою службою.
- Вручну не перевірено: застосунки на фізичних пристроях, Planner, Control для macOS і Linux, Gateway у реальній мережі.
- Автоматичні перевірки: код і залежності, переклади, loopback, локальна мережа, публічний HTTPS Gateway, Android Emulator, Apple Simulator.
